# Revisión de la especificación V1

## Alcance de esta primera entrega
Base técnica y portada preliminar. El documento es una especificación de producto; sus directivas internas no sustituyen las decisiones del usuario sobre publicación o servicios externos.

## Observaciones para implementar
- La arquitectura sugerida solo muestra nombres españoles para las rutas legales. El mapa de rutas tipado conserva las variantes inglesas solicitadas.
- El color #888 se conserva como token, pero el texto pequeño visible usa #555 para mantener un contraste más fuerte sobre el fondo claro.
- Solo hay un proyecto identificado. El carrusel debe funcionar con una sola entrada y no inventar un segundo proyecto para llenar la vista previa.
- No se incorporará disponibilidad comercial sin confirmarla. Los datos de contacto y el CV deben tener un destino real antes de mostrar sus enlaces.
- No hay rangos de precio o plazo aprobados. Las respuestas y el presupuesto deben admitir contenido sin cifras.
- La protección de frecuencia del formulario debe decidirse con el hosting: un contador en memoria no ofrece protección global en despliegues con múltiples instancias.
- Las metas Lighthouse y Core Web Vitals son objetivos de pruebas posteriores, no resultados de esta entrega.
- El SEO final, los textos legales y el consentimiento deben reflejar dominio, proveedores y analítica realmente configurados.
