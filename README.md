# Samuel Revollo — Portafolio
Implementación gradual de Development Spec V1. Idioma principal: español. Dirección: Monochrome Precision.

## Desarrollo
- npm install
- npm run dev
- Abrir http://localhost:3000/es
- npm run lint
- npm run build

## Estado
Etapa 1: base Next.js, TypeScript estricto, Tailwind, Hanken Grotesk y JetBrains Mono, tokens, portada preliminar y rutas ES/EN.
Las fuentes se descargan durante la compilación y se sirven desde la aplicación.
Vista incompleta con noindex. No contiene formulario operativo ni analítica.

## Pendientes de contenido
Capturas, año, descripción y URL de Acevedo Pucci; WhatsApp; correo receptor; LinkedIn; GitHub; CV; dominio; disponibilidad actual; textos comerciales, traducciones y legales revisados.

## Decisiones
- No se inventan proyectos, métricas ni datos de contacto.
- Los CTA se incorporarán al implementar sus destinos.
- Rutas legales inglesas: /en/privacy, /en/cookies y /en/terms.
- Canonical y hreflang se emiten cuando NEXT_PUBLIC_SITE_URL está configurado.
- Eliminar noindex solo al completar la revisión de lanzamiento.
- Presupuesto: sin rangos numéricos hasta su aprobación.
- Sin base de datos, CMS ni panel administrativo en V1.
- La especificación está conservada en docs/development-spec-v1.md.
