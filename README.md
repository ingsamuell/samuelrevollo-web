# Samuel Revollo — Portafolio web

Portafolio bilingüe de Samuel Revollo, desarrollador web. Presenta servicios, proceso de trabajo, proyectos seleccionados y un canal directo de contacto para empresas y profesionales que buscan una presencia digital clara, moderna y preparada para crecer.

Sitio en producción: [samuelrevollo.vercel.app](https://samuelrevollo.vercel.app)

## Características

- Rutas en español e inglés.
- Diseño editorial responsive, optimizado para escritorio y móvil.
- Galería accesible de proyectos con soporte táctil.
- Formulario de contacto con envío mediante Gmail y enlace de WhatsApp.
- Metadatos sociales, sitemap, robots.txt y rutas legales localizadas.
- Sin métricas, clientes ni resultados inventados.

## Stack

Next.js, React, TypeScript, Tailwind CSS y Nodemailer. El sitio se despliega en Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000/es](http://localhost:3000/es).

Para validar el proyecto:

```bash
npm run lint
npm run build
```

## Variables de entorno

Copia `.env.example` como `.env.local` y completa las variables requeridas. Nunca subas `.env.local` ni contraseñas de aplicación al repositorio.
